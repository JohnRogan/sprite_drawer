# Sprite Drawer

A simple pixel-art editor for making game sprites. Draw pixel by pixel, trace
over a photo, and save PNG files ready for Unity.

Click your computer type below to see the steps.

<details>
<summary><b>🪟 Windows</b></summary>

### 1. Get the files

Download this project as a ZIP (green **Code** button → **Download ZIP**).
Right-click the ZIP → **Extract All…** → **Extract**.

### 2. Install (one time only)

Open the extracted folder, open the **`installation`** folder, and
double-click **`install_windows.bat`**.

- If you see *"Windows protected your PC"*, click **More info** → **Run anyway**.
- It downloads everything it needs (including Python). Wait for **Install complete!**, then press any key.

### 3. Learn the controls

Open **[CONTROLS.md](CONTROLS.md)** to learn how to make a sprite, add a photo
underlay, and use the keyboard shortcuts.

### 4. Start Sprite Drawer

Double-click **`run_windows.bat`** in the **`installation`** folder. Leave the black window open while you
draw; closing it closes the app.

Prefer typing? In a terminal opened in this folder, run:

```
.venv\Scripts\python main.py
```

</details>

<details>
<summary><b>🍎 macOS</b></summary>

### 1. Get the files

Download this project as a ZIP (green **Code** button → **Download ZIP**).
Double-click the ZIP to unzip it.

### 2. Install (one time only)

1. Open **Terminal**: press **Cmd + Space**, type `Terminal`, press **Return**.
2. Type `bash ` (with a space after it). Don't press Return yet.
3. Drag **`install_mac.command`** from the project's **`installation`** folder into the Terminal window.
4. Press **Return**.

It downloads everything it needs. If Python is missing, it will ask for your
Mac password (nothing shows as you type; that's normal). Wait for
**Install complete!**

### 3. Learn the controls

Open **[CONTROLS.md](CONTROLS.md)** to learn how to make a sprite, add a photo
underlay, and use the keyboard shortcuts.

### 4. Start Sprite Drawer

In Terminal, type `bash ` (with a space), drag **`run_mac.command`** (in the
**`installation`** folder) into the window, and press **Return**. Leave Terminal open while you draw.

Prefer typing? In Terminal, from this folder, run:

```
.venv/bin/python main.py
```

</details>
